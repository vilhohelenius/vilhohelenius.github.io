# vilhohelenius.github.io

My portfolio site: https://vilhohelenius.github.io

A single static page (`index.html`) with inline CSS and a small inline script for the marathon pace sheet in the hero. No build step. Screenshots live in `img/`. The only external resource is the Archivo font from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Pushing to `main` publishes the site through GitHub Pages.
